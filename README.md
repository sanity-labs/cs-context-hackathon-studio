# Context Hackathon Studio

The Sanity Studio for enterprise organizations running a Context Hackathon with Sanity, where teams build AI agents on their own content.

It works with a chat app Sanity sets up for each hackathon, so on its own it won't do much. If you'd like to run one, talk to your Sanity Solution Architect (SA).

## Set it up

If you're preparing a hackathon with Sanity, you need Node.js 22.12 or later. Then run:

```sh
npx degit sanity-labs/cs-context-hackathon-studio context-hackathon && cd context-hackathon && npm install && npm run hackathon
```

The setup explains each step as it goes. Your SA will guide you through the rest.
